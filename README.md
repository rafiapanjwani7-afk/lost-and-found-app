# 🔍 Lost & Found Web Application

A full-stack, real-time **Lost & Found** web application designed to help users report, search, and manage lost or found items effortlessly. Built with a responsive dark-themed UI and powered by Supabase for real-time data synchronization.

🌐 **Live Demo:** [three-rose.surge.sh](https://three-rose.surge.sh)

---

## ✨ Features

- 📌 **Live Item Reporting:** Users can submit lost or found items with title, status, description, and visual evidence/images.
- 🎨 **Modern Dark UI:** Fully responsive dashboard built with Bootstrap 5 featuring subtle card hover effects and clear status badges.
- ⚡ **Real-Time Syncing:** Instant updates powered by Supabase backend authentication and database.
- 🛠️ **Admin Control Dashboard:** Complete panel for admins to view active logs, search/filter items, and toggle statuses (`Lost`, `Found`, `Resolved`).

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
- **Backend & Database:** Supabase (Auth & Database)
- **Deployment:** Surge / Netlify
